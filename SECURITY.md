# Security Policy

## Responsible Use Guidance

`mcpscan` is designed to assist developers and security teams in identifying common security misconfigurations and suspicious indicators in Model Context Protocol (MCP) server definitions.

- Only run scans against MCP servers that you own or have explicit authorization to test.
- Be aware that `mcpscan` executes stdio commands that spawn child processes locally; only scan trusted server packages or run scans in an isolated container/sandbox.

## Reporting a Vulnerability

If you discover a security vulnerability in `mcpscan` itself, please do not disclose it publicly via GitHub issues.

Instead, please send an email to:
**anshvishwa1212@gmail.com**

Please include:
- A clear description of the vulnerability.
- Steps to reproduce or proof-of-concept.
- Potential impact and suggested mitigations.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure.
