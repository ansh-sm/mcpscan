# mcpscan 🛡️

**Industrial-grade security posture analyzer and vulnerability scanner for Model Context Protocol (MCP) servers.**

Connects to any MCP server, evaluates tool definitions, schema constraints, and resource boundaries, detecting prompt injection, privilege creep, secret exposure, and token exhaustion vectors.

Produces actionable terminal scorecards and OASIS SARIF 2.1.0 output for CI/CD integration.
